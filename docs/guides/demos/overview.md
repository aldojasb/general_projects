## **Dev Container**  
[View on GitHub](https://github.com/aldojasb/my_devcontainer)  

A **pre-configured development environment** that ensures consistency and isolation across development setups.  

**Why it Matters?**  
Development environments can vary across machines, leading to inconsistencies and "works on my machine" issues. This dev container provides an isolated environment with all necessary tools and dependencies, ensuring that the development setup is uniform across all team members.  

**Key Features:**  
- Isolated development environment to prevent conflicts with host systems.  
- Pre-installed tools and libraries, such as Python, pyenv, and Poetry.  
- Reproducible setups ensuring consistency across different machines.  
- Simplifies onboarding for new developers by providing a ready-to-use environment.

## Hands-on Reinforcement Learning Application: PPO for Chemical Process Control
[View on GitHub](https://github.com/aldojasb/general_projects/tree/main/rl_cstr_optimization)  

A comprehensive implementation of **Proximal Policy Optimization (PPO)** for industrial chemical process control, demonstrating how reinforcement learning can optimize complex, safety-critical operations.

**Why it Matters?**  
Chemical manufacturing faces a fundamental challenge: balancing production efficiency with safety constraints. Traditional control systems often operate conservatively, sacrificing throughput for safety. This project shows how **RL agents can learn optimal control strategies** that maximize production while maintaining strict safety margins. The CSTR environment represents real-world scenarios where operators must continuously adjust cooling systems to prevent runaway reactions while maximizing yield.

**Key Capabilities[Work In Progress]:**  
- Detailed explanations of PPO concepts with real-world analogies and examples
- Complete PyTorch codebase with actor-critic networks and training loops
- Real-world considerations for deploying RL in safety-critical environments
- Tools for comparing RL performance against traditional control methods
- Built-in validation and monitoring systems for reliable operation
- Modular design that can be adapted to other industrial control problems
